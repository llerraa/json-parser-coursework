# JSON Parser с многопоточной обработкой

Курсовая работа по C++: парсер JSON с поддержкой многопоточной обработки больших файлов.

## 🚀 Новые возможности

### ✅ Многопоточная обработка
- Парсинг больших JSON-массивов в несколько потоков
- Автоматическое разделение на батчи
- Поддержка от 1 до N потоков

### ✅ Бенчмаркинг
- Сравнение однопоточной и многопоточной обработки
- Измерение ускорения (speedup)
- Тесты с 1, 2, 4 и 8 потоками

### ✅ Генератор тестовых данных
- Создание JSON файлов произвольного размера
- Генерация реалистичных данных (users, addresses, tags)
- Поддержка файлов до 500+ МБ

## 📝 Технические детали

### Алгоритм многопоточной обработки

1. **Парсинг:** Весь JSON парсится в одном потоке
2. **Разделение:** Массив делится на N батчей (по числу потоков)
3. **Обработка:** Каждый поток обрабатывает свой батч
4. **Объединение:** Результаты собираются в финальный массив

```
Array [0...999]
    ↓
Thread 1: [0...249]    Thread 2: [250...499]
Thread 3: [500...749]  Thread 4: [750...999]
    ↓
Merge results → Final array
```

### Синхронизация

- **std::thread** для создания потоков
- **std::mutex** для синхронизации вывода
- **std::vector** для хранения результатов
- **thread.join()** для ожидания завершения

### Почему не все масштабируется линейно?

1. **Overhead создания потоков** (~1-2 мс на поток)
2. **Синхронизация** между потоками
3. **Объединение результатов** в финальный массив
4. **Ограничение памяти** (cache contention)

Оптимальное ускорение обычно 0.8-0.9 от числа потоков.
